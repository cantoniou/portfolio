# Constantinos Antoniou — research portfolio

Public portfolio of Prof. Dr. Constantinos Antoniou and the Chair of Transportation Systems Engineering (TSE), Technical University of Munich. Static site on GitHub Pages; all content lives in `data/*.json`.

- **New here?** Read `START-HERE.md`, then open the folder in Claude and say "Onboard me".
- **Help desk (what to say to Claude for each task):** open `help/index.html` or the live `/help/` page
- **To update content:** see `MAINTAINING.md` (or open the folder in Claude and describe the change).
- **To preview locally:** `python3 -m http.server 8000` then open http://localhost:8000
- **To refresh publication figures:** `python3 scripts/refresh_openalex.py`
- **To verify before publishing:** `python3 scripts/check_consistency.py`
- **Anniversary presentation (2026):** `anniversary/`

Claude skills for these tasks are in `.claude/skills/` and load automatically when the repository is opened in Claude.
